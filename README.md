# 🌤️ Weather App

A simple weather app that shows live weather for any city, built with HTML, CSS and JavaScript using the OpenWeatherMap API.

🔗 **Live Demo:** https://harmanjoshi1654.github.io/Weather-app/

<img width="1917" height="972" alt="image" src="https://github.com/user-attachments/assets/c688d352-50b1-4789-a541-45c1c037c0f3" />


## Features

- Search weather by city name
- Shows temperature, weather description and icon
- Shows feels-like temperature, humidity and wind speed
- Shows an error message for invalid cities
- Clean, centered card layout

## Tech Stack

| Technology | Used for |
|------------|----------|
| HTML5 | Page structure |
| CSS3 (Flexbox) | Styling and layout |
| JavaScript (ES6) | Logic, fetch API, async/await, DOM updates |
| OpenWeatherMap API | Live weather data |

## What I Learned

- Fetching data from a REST API using `fetch` and `async/await`
- Handling errors with `try/catch`
- Updating the DOM dynamically
- Deploying a static website with GitHub Pages

## Run Locally

1. Clone the repo: `git clone https://github.com/harmanjoshi1654/Weather-app.git`
2. Open `index.html` in your browser (or use VS Code Live Server)
3. Get a free API key from OpenWeatherMap and put it in `script.js`
